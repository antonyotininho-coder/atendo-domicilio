# Atendo à Domicílio

Aplicativo web para gestão de manicure e pedicure em domicílio.

## Stack

- Next.js 14
- React 18
- Tailwind CSS
- TypeScript

## Execução local

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o projeto em desenvolvimento:
   ```bash
   npm run dev
   ```
3. Abra no navegador:
   ```bash
   http://localhost:3000
   ```

## Páginas principais

- `/login`
- `/dashboard`
- `/agenda`
- `/clientes`
- `/configuracoes`

## Observação

Este é um scaffold inicial em frontend com visual moderno e identidade customizada. O app inclui autenticação simulada em cliente para demonstrar fluxo e UI do sistema.
